# 🔊 Text to Voice Converter

A simple and user-friendly **Text to Voice Converter** web application that converts written text into spoken audio using the browser's built-in Speech Synthesis API. Users can enter text, select a voice and listen to the generated speech instantly.

## 🚀 Live Demo

Check out the project here:

[Text to Voice Converter Repository](https://github.com/Bineth-Tharana/Text-to-Voice-Converter?utm_source=chatgpt.com)

---

## 📌 Features

* 📝 Convert text into speech instantly
* 🎙️ Multiple voice options (depending on browser support)
* 🌐 Uses the Web Speech API
* ⚡ Fast and lightweight
* 📱 Responsive design
* 🎨 Clean and modern user interface
* 🔄 Real-time speech generation
* 🛠 No external libraries required

## ⚙️ How It Works

1. Enter the text you want to convert into speech.
2. Select an available voice from the dropdown list.
3. Click the **Listen** button.
4. The browser converts the text into spoken audio.
5. Enjoy the generated speech output.
